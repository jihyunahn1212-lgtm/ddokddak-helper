# Supabase 설정 안내 (똑딱 정리 도우미)

웹앱의 "☁️ 클라우드 저장"을 켜려면 Supabase 프로젝트가 필요합니다.
이 안내를 따라 만든 뒤 **프로젝트 URL**과 **공개용 키** 두 가지만 웹앱 코드에 넣으면 됩니다.

> 이 앱은 **포트폴리오 데모**입니다. 클라우드에는 **가짜 데이터로 만든 작업 내용만** 저장하세요.

## 서버에 저장되는 것 / 안 되는 것
| 저장됨 | 저장 안 됨 |
|---|---|
| 일자 수정, 제외한 행의 전표번호, 직접 추가한 항목(일자·거래처·적요·금액), 심사완료 체크한 전표번호, 전일잔액·목표 잔액·최종 요청시재 등 입력값 | 원본 엑셀 파일, 거래 행 내용, 파일 이름, 입금·출금 합계 |
| 파일 구분 키(SHA-256 해시 64자) | |

## 1단계. 프로젝트 만들기
1. Supabase 대시보드에서 **New project**를 누릅니다.
2. 아래처럼 입력합니다.
   - **Name**: `ddokddak-helper`
   - **Database Password**: 생성 버튼으로 만들고 **비밀번호 관리자에 보관**합니다. (이 앱은 이 비밀번호를 쓰지 않습니다. 누구에게도 보내지 마세요.)
   - **Region**: Northeast Asia (Seoul)
   - 나머지는 기본값(무료)
3. **Create new project**를 누르고 1~2분 기다립니다.

## 2단계. 테이블 만들기
1. 왼쪽 메뉴 **SQL Editor → New query**
2. [`schema.sql`](schema.sql)의 내용을 전부 붙여넣고 **Run**을 누릅니다.
3. `Success. No rows returned`가 나오면 끝입니다. (Table Editor에 `work_saves`가 보입니다.)

## 3단계. 로그인 설정
1. 왼쪽 메뉴 **Authentication → Sign In / Providers**에서 **Email**이 켜져 있는지 확인합니다.
2. **Authentication → URL Configuration**
   - **Site URL**: `https://ddokddak-helper.vercel.app`
   - **Redirect URLs**에도 같은 주소를 추가합니다.
3. **가입 방식을 하나 고릅니다.**
   - **Confirm email 켜기(기본값, 권장)**: 가입 후 메일의 링크를 눌러야 로그인됩니다. 가짜 이메일로 마구 가입하는 것을 막아 줍니다.
   - **Confirm email 끄기**: 바로 로그인됩니다. 데모 시연은 편하지만 누구나 가입할 수 있습니다.
4. (선택) 본인 계정만 쓰고 싶다면 계정을 만든 뒤 **Sign In / Providers → Allow new users to sign up**을 끕니다. 이후에는 방문자가 가입할 수 없습니다.

## 4단계. URL과 공개용 키 확인
1. **Project Settings(톱니바퀴) → API Keys**를 엽니다. (또는 위쪽 **Connect** 버튼)
2. 다음 두 가지를 복사합니다.
   - **Project URL**: `https://xxxxxxxxxxxx.supabase.co`
   - **공개용 키**: `anon` 키(`eyJ…`로 시작) 또는 **publishable** 키(`sb_publishable_…`로 시작)
3. 이 두 가지를 웹앱 코드에 넣습니다. 공개 저장소에 올라가도 괜찮게 설계된 값입니다. 접근 제한은 2단계의 RLS가 담당합니다.

### 절대 넣거나 보내지 말아야 하는 것
- `service_role` 키, **secret** 키(`sb_secret_…`): 접근 제한을 우회하는 관리자 키입니다.
- Database Password
- JWT secret

## 참고
- **가입 확인 메일은 Supabase 기본 메일 서비스로 발송됩니다.** 이 서비스는 시험용이라 **시간당 발송 횟수가 매우 적고**, **프로젝트 조직 구성원의 이메일 주소로만** 보낼 수 있습니다. 그래서 본인(조직 소유자) 이메일로는 가입 확인이 되지만, 다른 방문자는 확인 메일을 받지 못할 수 있습니다. 방문자도 가입하게 하려면 Authentication → SMTP Settings에서 별도 메일 서비스를 연결해야 합니다.
- 무료 프로젝트는 **약 1주일 동안 접속이 없으면 일시 정지**될 수 있습니다. 대시보드에서 Restore를 누르면 복구됩니다.
- 프로젝트를 지우면 저장된 작업 내용도 함께 사라집니다.
