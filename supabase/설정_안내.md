# Supabase 설정 안내 (똑딱 정리 도우미)

웹앱의 "☁️ 클라우드 저장"은 **로그인 없이** 쓰는 방식입니다. 방문자가 처음 💾 저장을 누르면 Supabase의 **익명 로그인**으로
**이 브라우저 전용 저장공간**이 자동으로 만들어지고, 그 안에 작업 내용이 저장됩니다. 이메일·비밀번호가 필요 없습니다.

## 서버에 저장되는 것 / 안 되는 것
| 저장됨 | 저장 안 됨 |
|---|---|
| 일자 수정, 제외한 행의 전표번호, 직접 추가한 항목(일자·거래처·적요·금액), 심사완료 체크한 전표번호, 전일잔액·목표 잔액·최종 요청시재 등 입력값 | 원본 엑셀 파일, 거래 행 내용, 파일 이름, 입금·출금 합계 |
| 파일 구분 키(SHA-256 해시 64자) | 이메일·이름 등 사용자 정보(익명이라 없음) |

## 접근 방식
- 저장공간은 **브라우저마다 따로**입니다. 같은 브라우저에서 같은 파일을 올리면 불러올 수 있고, 브라우저 데이터를 지우거나 "클라우드 연결 끊기"를 누르면 그 저장공간에는 다시 접근할 수 없습니다.
- 접근 제한(Row Level Security)이 걸려 있어서 **다른 사람의 저장본은 읽을 수도 쓸 수도 없습니다.** 로그인하지 않은 요청(anon)은 테이블에 접근할 수 없습니다.
- 화면의 **"이 파일의 클라우드 저장본 삭제"** 로 언제든 지울 수 있습니다.

## 1단계. 프로젝트 만들기
1. Supabase 대시보드에서 **New project**를 누릅니다.
2. **Name** `ddokddak-helper`, **Database Password**는 생성 버튼으로 만들어 비밀번호 관리자에 보관(이 앱은 쓰지 않습니다. 누구에게도 보내지 마세요), **Region**은 Northeast Asia (Seoul)로 합니다.
3. **Create new project**를 누르고 1~2분 기다립니다.

## 2단계. 테이블 만들기
1. 왼쪽 메뉴 **SQL Editor → New query**
2. [`schema.sql`](schema.sql)의 내용을 전부 붙여넣고 **Run**을 누릅니다.
3. `Success. No rows returned`가 나오면 끝입니다. (Table Editor에 `work_saves`가 보입니다.)

## 3단계. 익명 로그인 켜기 (필수)
1. 왼쪽 메뉴 **Authentication → Sign In / Providers** (또는 **Settings**)를 엽니다.
2. 아래로 내려서 **Allow anonymous sign-ins** 스위치를 **켭니다**.
3. **Save**를 누릅니다.

> 이 스위치가 꺼져 있으면 웹앱에서 💾 저장을 눌렀을 때
> "Supabase에서 '익명 로그인'이 꺼져 있어요"라는 안내가 나옵니다. (이 브라우저 저장은 그대로 됩니다.)
>
> **CAPTCHA는 켜지 마세요.** 이 웹앱은 CAPTCHA를 지원하지 않아서, 켜면 익명 로그인이 막힙니다.

## 4단계. URL과 공개용 키 확인
1. **Project Settings(톱니바퀴) → API Keys**를 엽니다. (또는 위쪽 **Connect** 버튼)
2. 다음 두 가지를 웹앱 코드(`웹앱/index.src.html`의 `SUPABASE_URL`, `SUPABASE_KEY`)에 넣습니다.
   - **Project URL**: `https://xxxxxxxxxxxx.supabase.co`
   - **공개용 키**: `sb_publishable_…` 또는 `anon` 키(`eyJ…`)
3. 같은 주소를 `vercel.json`의 `connect-src`에도 넣어서, 이 주소 한 곳만 외부 통신을 허용하게 합니다.

### 절대 넣거나 보내지 말아야 하는 것
- `service_role` 키, **secret** 키(`sb_secret_…`): 접근 제한을 우회하는 관리자 키입니다.
- Database Password
- JWT secret

## 운영 참고
- **익명 사용자가 계속 쌓입니다.** 방문자가 저장할 때마다 사용자가 하나씩 생깁니다. 필요하면 SQL Editor에서 오래된 익명 사용자와 그 저장본을 정리하세요.
  ```sql
  -- 30일 넘은 익명 사용자 삭제 (저장본도 함께 삭제됨)
  delete from auth.users
  where is_anonymous and created_at < now() - interval '30 days';
  ```
- 익명 로그인은 Supabase 기본 설정에서 **IP당 시간당 30회** 정도로 제한됩니다(Authentication → Rate Limits에서 확인·변경). 저장 한 건은 200KB 미만으로 제한됩니다(`schema.sql`).
- 무료 프로젝트는 **약 1주일 동안 접속이 없으면 일시 정지**될 수 있습니다. 대시보드에서 Restore를 누르면 복구됩니다.
- 프로젝트를 지우면 저장된 작업 내용도 함께 사라집니다.
